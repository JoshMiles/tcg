OBS connection

In OBS open Tools > WebSocket Server Settings, tick "Enable WebSocket server", and copy the Server Password here (OBS 28 or newer; leave it empty if you switched authentication off). TCG Bridge only talks to OBS on this PC. It tells the site when the stream starts and stops, which scene is on air, and whether the TCG overlay browser source is in that scene and visible. An overlay inside a nested scene is not seen.
