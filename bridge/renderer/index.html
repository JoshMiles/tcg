                      How?

                      In OBS open Tools > WebSocket Server Settings, tick "Enable WebSocket server", and copy the Server Password here (OBS 28 or newer; leave it empty if you switched authentication off).                         Pause pulls on scenes

                          Live stats in OBS

                          How?

                          Pick an OBS text source (GDI+ or FreeType text) for each stat you want on screen. TCG Bridge writes only the text, at most once a second and only when it changes. A stat set to "Not shown" never touches a source, so its text stays as it is. Needs OBS connected on the Connections page.

                            OBS connection

                            The address, password, replay buffer and Start OBS with TCG Bridge are on the OBS connection.

                            Stream Deck buttons

                            How?

                            In the Stream Deck app add a "Website" action, paste the address, and tick "GET request in background". The address has a secret key in it: do not share it. Only this PC can use it.

                            Hotkeys

                            How?

                            When the site asks (a switch on its Mix It Up page, off by default), TCG Bridge saves every viewer's Brie Bucks as a CSV here at the start and end of a stream, and keeps the newest 30.
