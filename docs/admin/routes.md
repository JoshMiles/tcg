# Admin routes

> Read this when you touch which admin page lives where, the pack library and pack page extras, the Settings tabs.

## Admin routes
- `/admin`. The **widget dashboard** (see "Admin dashboard (widgets)"): stats, quick actions, top collectors, leaderboard, rarity mix, packs, card ownership, recent activity, trading, overlay status, activity pulse, variant mix, most valuable cards, cards nobody owns, stream status, shortcuts and notes, arranged by the admin. The header links to the staff wiki (`/admin/wiki`)
- `/admin/wiki` and `/admin/wiki/[slug]`. **Staff wiki**: topics rendered from `content/wiki/*.md` (overview, viewers, cards, trading, live tools, moderation, support, environments, glossary). Sidebar item Staff wiki (shortcut `g` then `k`). Admin layout only, so mods never see it
- `/admin/seasons`, season list (drafts first)
- `/admin/seasons/new[?draft=id]`, season wizard / resume a draft
- `/admin/seasons/[id]`, season settings + pack assignment
- `/admin/packs`, global pack library: search (matches season names too, `/` focuses it), status filters (All / Live / Inactive / Drafts) and sorting via `PackToolbar` (tiles opt in with `data-pack` + `data-*` attributes; it toggles `hidden` / CSS `order`, no re-render); each tile shows the seasons it is used in (a warning when a published pack is in none, so it can never be drawn), an Upgrades chip, a one-click Active/Inactive switch (`setPackActive`) and a link to that pack's overlay overrides (`/admin/overlay?scope=<id>`)
- **Pack library extras**: every published tile shows a **health** badge (`packHealth()` in the client-safe `lib/pack-health.ts`: no cards, 0-odds cards, missing images / names, duplicate card numbers, Full Art cards without art, Regular weight 0, duplicate names, no cover, not in any season; links to `/admin/packs/[id]#health`) and the pack's **usage** (`pulls · % of draws`, from the per-pack counters `p:<pack name>` in `lib/stats.ts`, so it counts from when tracking began and follows the pack's name). Tiles also have **Duplicate** (`duplicatePackAction`: a draft copy named "<name> (copy)" with the same settings and cards under new ids; card numbers are copied, so renumber if both packs go in one season) and **Archive / Restore** (`Pack.archived`: hidden under the Archived filter, never drawn, can't be switched on, its cards stay so collections keep working; restore brings it back inactive). The actions live in `app/admin/pack-actions.ts`.
- **Pack page extras**: header Duplicate / Archive, a Pack health panel, and an **Odds & simulator** panel (`OddsPanel.tsx`): edit every card's weight in one table with live chance / "1 in N", Normalize to 100, Balance by rarity (set the share of pulls per star tier; cards in a tier share it equally), a share-by-rarity chart, and a draw simulator (1,000 / 10,000 / 100,000 packs from the weights typed, saved or not, with the variant roll and a 300-trial estimate of the packs needed to find every card). Saving goes through `savePackOddsAction`.
- **Card editor** (`cards/[cardId]/CardEditor.tsx`): the form is client-controlled, with a live **preview** beside it (the card with its Overlay Editor holo and variant look, per allowed version, from `holoByStars` computed server-side because the holo's "auto" mode depends on the star rating) and real-time **checks** (name / number clashes, no image, unoptimised GIF, Full Art with no art, 0 or unusual odds, odds out of line with the rarity). It still posts to the same `updateCard` action.
- `/admin/packs/new[?draft=id]`, pack wizard / resume a draft
- `/admin/packs/[packId]/cards`, bulk card editor for an existing pack (explicit save)
- `/admin/packs/[packId]`, pack page: header actions (activate / overlay look), a "Used in" seasons panel, a searchable / rarity-filterable cards table (`CardFilter`, same data-attribute approach), pack settings with a sticky Save, move to drafts, and a danger zone (delete)
- `/admin/packs/[packId]/cards/[cardId]`, edit individual card
- `/admin/trades`, Trades: summary tiles, offers-per-day chart, top traders / cards, a searchable filterable log (`TradeLog`; click a row for the detail panel: both sides, points, flags, cancel / extend / block viewer; CSV export), bulk controls (`TradeControls`: per-season trading switch, extend all, cancel & refund by scope) and settings
- `/admin/users`. All collectors: summary tiles, search + filter chips (tags, complete, shiny, restricted, notes), sort, columns, CSV export, bulk gift / tag (`UsersList`)
- `/admin/users/[username]`, user detail: overview tiles, tags, notes, timeline, trades (admin cancel), per-season grids, multi-card grant, compare (`?compare=`), moderation, restore points, merge, audit trail, danger zone
- `/admin/activity`, live activity feed
- `/admin/assets`, media library (see "Assets page" under Admin UX conventions): card art / pack covers / sounds / Unused / Insights tabs, detail panel, bulk fix, replace-in-place, selectable cleanup
- `/admin/webhooks`, redirects to Settings → Webhooks (incoming/outgoing webhooks + Discord feed now live in that tab; the components are `app/admin/settings/WebhookConfig.tsx` / `DiscordConfig.tsx`)
- `/admin/overlay`. The **Overlay Editor** (layout + look in one workspace; `/admin/settings?tab=layout|look` redirect here)
- `/admin/buffs`, **Buff Editor for Trainer Cards** (sidebar, Game group, key `g r`): list, create, edit and delete reusable buff definitions (`trainer:buffs` in `lib/buffs.ts`, pure model in `lib/buffs-core.ts`). Deletion is refused while any trainer card or achievement points at the buff; mutations use `ArmedButton` and `recordAudit`
- `/admin/mixitup`, **Mix It Up** (sidebar, Game group, key `g m`; `/admin/settings?tab=mixitup` redirects here): tabs Paid pulls (the Track 12 form and Try it buttons), Log (recent requests); see "Mix It Up paid pulls"
- `/admin/sandbox`, create and enter sandboxes (isolated copies of the data for testing upgrades / trades); `/admin/sandbox/[id]`, test users, simulated pulls, grant exact copies, log in as a test user, reset / delete
- `/admin/settings`, **tabbed** (`?tab=overlay|scoring|achievements|webhooks|viewers|environment|about`, server-rendered via `PageTabs`) under a row of status tiles (environment, Twitch extension, scoring changes, webhooks, build). **OBS Overlay**: source URL, connection (`OverlayStatus`), a test trigger (`OverlayTest`, the dashboard's `quickAction` 'show'), the two "only when live" switches (`LiveGates`, saved on flip through `setLiveGateAction`) and the bot snippet (`CopyBlock`). **Scoring**: `ScoringForm` (client) with a live preview: `previewScoringAction` → `previewScoring()` (`lib/scoring-preview.ts`, pure) re-scores the active season with the typed numbers next to the saved ones (set value, top scores, bonuses, top 5, rank changes) before anything is stored; edits are flagged, out-of-range values show what they will clamp to, and leaving with unsaved edits warns (`beforeunload`). **Achievements**: one row per built-in kind (on/off, title, detail; a blank box keeps the built-in words), stored at `achievements:settings`. **Twitch & viewers**: the copyable extension checklist from `lib/twitch-setup.ts` (panel / mobile / video URLs, privacy + terms, fetch allowlist, OAuth redirect) plus secret chips. **Environment**: `lib/env-health.ts` (`checkEnv`, pure) lists which variables are set (never their values), required / recommended / optional and what each unlocks, flagging short secrets. Add a new variable to `ENV_SPECS`. Saves redirect back with `&saved=<key>` and show a banner; add new settings to the matching tab and a `SAVED_MESSAGES` entry. Every settings action calls `requireAdmin()`. `scripts/check-settings.mts` (pure) covers clamping, the preview, the environment list and the setup list.
