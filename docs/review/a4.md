# Review batch A4: people

Pages: `/admin/users` (list, filters, selection, bulk actions, export), `/admin/users/[username]` (Profile, Collection, Trades, Grant, Admin tabs, compare) and `/admin/staff`. Seeded with `scripts/seed-review.mts`, swept with `scripts/sweep-admin.mjs` at 390, 768 and 1280 px, then walked by hand in a browser (search and every filter chip, selection and bulk gift, profile save, tags, grant, reset a season then restore it, merge dialog, compare, adding / removing staff, the Reset All dialog).

## Sweep

All people pages clean at the three widths. The duplicate-key console warnings that the tooling run noted on `?tab=grant` no longer appear (checked in a browser; none).

## Bugs (fixed)

1. **The Users list counted draft packs' cards.** The "Complete collection" filter, the Complete tile and each row's `20/25 · 80%` used every pack attached to a season, including draft packs that can never be pulled, so a viewer who had every card showed 80% and was not "complete" (the leaderboard and the viewer's own page, which skip draft packs, said Complete). The totals now use the same set the leaderboard uses (published packs, by card number). The seeded `completionist` reads `20/20 · 100%` and the Complete filter gives 8, the same as the leaderboard.
2. **Server actions that take a collection name trusted it.** `removeUserCard` and `resetUserSeason` received the collection name as an argument and would act on any `tcg_<name>` key; they now require it to be one of the seasons' collections. `resetUser` did not lower-case the name (it matched only if the URL was already lower-case); it does now.
3. **Dead `grantUserCard` action removed.** Nothing called it. It was a public admin action that granted any card number (including one that does not exist, or one above 1,000,000 which decodes as another version) with none of the checks the Grant tab's action has.
4. **Unbounded profile fields.** The display name, Twitch username and notes had no length limit, server or client; they are capped (60, 60 and 2,000 characters).

## Safer actions (fixed)

- **Reset All** (wipes every viewer's cards in every season, no restore point) was one dialog with a red button. The shared `ConfirmButton` now has `typeToConfirm`: the confirm button stays off until "reset everyone" is typed.
- **Bulk Gift** queued packs for up to 50 selected viewers (500 openings on stream) in one click, even with no overlay connected. It is a confirmation now that states viewers, packs each and the total.
- `window.confirm` replaced: Remove staff (two-click `ArmedButton`), Restore point and Merge (the standard dialog; the merge dialog also warns that an unused name becomes a new account, so a typo is visible). A dead condition on the Merge button was removed.

## Visual and accessibility (fixed)

- The viewer page's tab shows the viewer's name; labels on the profile form are tied to their inputs; the joined date and the staff log times are fixed-format (`en-GB`, UTC).

## Checked and fine

Search, every filter chip and the empty state, selection, upper-case usernames in the URL, tags (add / remove), notes saved, per-season reset with its dialog, restore (the dialog states what is replaced; "Restored 4 cards"), compare, merge dialog, adding a staff member (a name that has not played yet is matched by name until first sign-in) and removing one.
