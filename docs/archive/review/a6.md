# Review batch A6: stream

Pages: `/admin/overlay` (the Overlay Editor, global and per-pack scope), `/overlay.html` itself (`?dev` test panel and `?preview`), and `/admin/assets` (all tabs). Seeded with `scripts/seed-review.mts`, swept with `scripts/sweep-admin.mjs` at 390, 768 and 1280 px, then walked by hand in a browser.

## Sweep

All pages clean at the three widths. The "one control with no accessible name" the tooling run noted on the Overlay Editor was a **false positive of the sweep**: it is the Pack-opening sounds switch, a `<button role="switch">` named by its `<label for>`, and the sweep only looked at the button's own text. The sweep (`scripts/lib/sweep.mjs`) now counts associated labels, so it no longer flags it (checked with `getByRole('switch', { name: 'Pack-opening sounds' })`).

## Hand pass

- **Editor:** a clean editor has Save and Revert off; a change turns them on; Ctrl+Z and Ctrl+Y undo and redo; an out-of-range number is brought to its limit (9 becomes 1.5 for Pack size); Review lists `Pack size 1 × → 1.2 ×`; Save keeps the value after reload and records a version; the Versions popover lists them with Load; a per-pack override saves and persists on its own scope; Import / Export reports "That is not valid JSON." for garbage and "Imported 1 setting. Review, then Save." for a mixed paste (the out-of-range value is clamped, the unknown key and the bad option are dropped).
- **Overlay page:** `/overlay.html?dev` loads without console errors, defaults to Don't save (dry run), D draws a card and C shows the collection without any request except the heartbeat; `?preview` sends nothing.
- **Assets:** search (and its empty message), Grid / Compact / List, opening the detail panel, arrow keys and Esc, every tab. Blob uploads, replace, fix and delete need a real deployment.

## Bug (fixed)

- **The editor's save accepted overrides for any pack id.** `saveOverlayEditorAction` wrote a per-pack override for every key in the posted payload, so a crafted request could leave stray keys in KV. It now saves overrides only for packs that exist (a normal save is unchanged: verified with a pack-scope save).
